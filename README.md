# Nikolaos Ziakos — Research Portfolio

Personal research portfolio for Nikolaos Ziakos, PhD candidate in Aerospace Engineering at Universidad Carlos III de Madrid.

Website: https://nickziakos.github.io/Personal-Website/

## Hosting

A static HTML/CSS website hosted with GitHub Pages. No paid domain, server, subscriptions, or visitor login is required. Enable Pages from the `main` branch and `/ (root)` directory in repository Settings → Pages.

## Update the portfolio

- Edit `index.html` for biography, projects, publications, education and links.
- Edit `styles.css` for appearance and responsive layout.
- Replace the corresponding PDF to update the research CV or diploma thesis.
- Add new images alongside the existing assets and reference them from HTML.
- Commit changes to `main`; GitHub Pages republishes automatically.

Submitted manuscripts and ongoing work are explicitly labeled. Certificate scans and unpublished manuscripts are not included in this repository.

## Local preview

Open `index.html` in a browser, or serve the directory using a local static web server. No package installation or build step is required.
